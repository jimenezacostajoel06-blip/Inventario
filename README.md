# BANCO
Es un programa diseñado para simular el funcionamiento de un banco, con funciones básicas de registro.

#### Visual Studio
- **Lenguaje:** C++
- **Frameworks / Librerías:** Aplicacion de Windows Forms



# GRANJA
Es un juego en el que se deben plantar semillas en los terrenos y esperar a que crezcan para poder cosecharlas.

#### Visual Studio
- **Lenguaje:** C++
- **Frameworks / Librerías:** Aplicacion de Windows Forms



# X y 0
Es un juego para dos jugadores en el que deben colocar X y O en un tablero de 3x3. El objetivo es conseguir tres símbolos iguales en línea, ya sea horizontal, vertical o diagonal, antes que el oponente.

#### Visual Studio
- **Lenguaje:** C++
- **Frameworks / Librerías:** Aplicacion de Windows Forms
